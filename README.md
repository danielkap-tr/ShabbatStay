# Shabbat Stay

פרויקט פשוט להצגת המלצות על דירות ומלונות מותאמים לשבת.

## מה קיים

- רשימת מקומות עם שם, כתובת, פרטי בעלים, מדינה, עיר
- ציון כללי, ציון כשרות, מצב התאמה לשבת
- סינונים לפי מדינה, עיר, ציון כשרות, ציון כללי, חיפוש חופשי
- טופס להוספת המלצה חדשה

## איך להפעיל

1. פתח את `index.html` בדפדפן.
2. השתמש בסינונים כדי למצוא מקומות לפי מדינה, עיר וכשרות.
3. הוסף המלצה חדשה באמצעות הטופס בצד.

## שיפור אפשרי

- שמירת הנתונים ב־localStorage או ב־backend
- הוספת ממשק ניהול והצגת מפה
- אימות טלפונים ודוא"ל
