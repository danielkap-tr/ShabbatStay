# Shabbat Stay

פרויקט פשוט להצגת המלצות על דירות ומלונות מותאמים לשבת.

## מה קיים

- רשימת מקומות עם שם, כתובת, פרטי בעלים, מדינה, עיר
- ציון כללי, ציון כשרות, מצב התאמה לשבת
- סינונים לפי מדינה, עיר, ציון כשרות, ציון כללי, חיפוש חופשי
- טופס להוספת המלצה חדשה
- אפשרות למארח/ת להירשם ישירות (צ'קבוקס "אני הבעלים") ולציין מספר אורחים/מיטות, מחיר ללילה ופרטי יצירת קשר
- שמירת המלצות שנוספו ב-localStorage (נשארות גם אחרי רענון הדף — אך שמורות רק בדפדפן/מכשיר הנוכחי, לא משותפות בין מבקרים באתר). לאיפוס לרשימת ברירת המחדל, יש לנקות את נתוני האתר בדפדפן (או להריץ `localStorage.removeItem('shabbatstay-listings')` בקונסולת המפתחים).

## איך להפעיל

1. פתח את `index.html` בדפדפן.
2. השתמש בסינונים כדי למצוא מקומות לפי מדינה, עיר וכשרות.
3. הוסף המלצה חדשה באמצעות הטופס בצד.

## שיפור אפשרי

- הוספת ממשק ניהול (עריכה/מחיקה) והצגת מפה
- אימות טלפונים ודוא"ל
